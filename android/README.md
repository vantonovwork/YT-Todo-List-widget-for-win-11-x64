# YouTrack задачи — Android

Порт десктопного виджета для Android 8–16 и HarmonyOS 2–4: один APK для планшета (Huawei) и телефона (OnePlus, OxygenOS 16).
HarmonyOS NEXT (5.x) APK не поддерживает.

## Возможности

- Список задач с поиском и фильтрами: приоритет, «горящие» сроки, спринт.
- Быстрый просмотр (описание + 3 последних комментария), счётчик новых комментариев.
- Полный просмотр задачи без браузера: всё описание, все комментарии, поля; текст можно выделить и скопировать.
  Оформление как в YouTrack: описание и комментарии берутся с сервера уже оформленными (HTML) — заголовки, списки, таблицы, код, цитаты, картинки.
- «Срочные» — свои короткие дела (название до 100 символов, текст до 1000), хранятся только на устройстве.
- Кнопка «Вставить» (значок буфера обмена) в полях комментария и срочной задачи — вставляет текст в позицию курсора с учётом лимита.
- Смена статуса, приоритета и спринта нажатием на плашку карточки (статус — только разрешённые workflow переходы;
  спринт — активные спринты: выбор переносит задачу, выбор текущего убирает из спринта).
- Комментарии в YouTrack прямо из приложения: «Написать комментарий» в быстром просмотре, в меню ⋮ и на экране задачи;
  черновик сохраняется при закрытии окна.
- «Нужно внимание» — незакрытые задачи, где вас упомянули через @ (запрос `mentions: me #Unresolved` в настройках):
  кто и когда упомянул, цитата, плашка «ждёт ответа / отвечено» (нажатием можно отметить вручную), уведомление «Вас упомянули».
- План на день: звёздочка, галочка «сделано» (до конца дня), порядок кнопками ↑↓ или перетаскиванием за ручку. Настраиваемые блоки («Требуется уточнение», «Анализ»…): кнопка «Блоки», перенос между блоками перетаскиванием или через меню карточки ⋮.
- Уведомления (проверка раз в 15 минут), каждый тип включается отдельно в «Настройки → Уведомления»:
  - новое упоминание — вас отметили через @;
  - новый комментарий — в ваших задачах и задачах под наблюдением;
  - смена статуса задачи под наблюдением (с именем того, кто сменил; свои изменения не показываются);
  - назначена новая задача.
  Задачи под наблюдением задаёт запрос в настройках, по умолчанию `tag: Star sort by: updated` (задачи со звёздочкой).
- Виджет на главный экран: план на день или все задачи.
- Установленная версия — внизу экрана «Настройки» (⚙).
- Журнал ошибок: «Настройки → Журнал» — записи об ошибках и падениях, кнопка «Отправить журнал». После падения приложение само предложит отправить отчёт.

## Установка на Huawei

1. Скопируйте `dist/YouTrackWidget-1.9.2.apk` на планшет и откройте его. Разрешите установку из этого источника.
2. При первом запуске укажите адрес YouTrack и постоянный токен (Профиль → Аккаунт и безопасность → Токены).
3. Чтобы уведомления приходили в фоне: **Настройки → Батарея → Запуск приложений → YouTrack задачи →
   «Управлять вручную»**, включите «Автозапуск», «Косвенный запуск» и «Работа в фоне».
4. Виджет: долгое нажатие на главном экране → Виджеты → «YouTrack задачи».

## Установка на OnePlus (OxygenOS 16)

1. Скопируйте `dist/YouTrackWidget-1.9.2.apk` на телефон и откройте его в «Файлах». Разрешите установку из этого источника.
2. При первом запуске разрешите уведомления и укажите адрес YouTrack и токен.
3. Настройки приложения → «Разрешить работу в фоне» → «Разрешить». Дополнительно: долгое нажатие на значке →
   «Сведения о приложении» → «Использование батареи» → включите «Разрешить фоновую активность» и «Автозапуск».
4. Виджет: щипок на главном экране → Виджеты → «YouTrack задачи».

## Сборка

Нужны JDK 17 и Android SDK (platform 34, build-tools 34.0.0). Путь к SDK — в `local.properties`
(`sdk.dir=...`, файл не в репозитории).

Android Gradle Plugin не собирает проект из папки с не-ASCII символами в пути (например, «Для работы»).
Подключите папку под временной буквой диска:

```powershell
subst Y: "F:\Для работы\YouTrackWidget"
cd Y:\android
$env:JAVA_HOME = "F:\Android\jdk17"; $env:GRADLE_USER_HOME = "F:\Android\gradle-home"
.\gradlew.bat testDebugUnitTest assembleRelease
subst Y: /d
```

APK: `app/build/outputs/apk/release/app-release.apk`.
Подпись берётся из `F:/Android/keys/keystore.properties` (ключ хранится вне репозитория;
путь можно переопределить: `-PytwKeystoreProps=...`). Без него APK подписывается debug-ключом.

**Ключ `F:\Android\keys\ytwidget-release.jks` и файл с паролем сохраните в надёжном месте:**
обновления APK устанавливаются поверх только с той же подписью.

## Структура

| Файл | Назначение |
|---|---|
| `Model.kt` | разбор задач и полей, сроки, спринты, цвета, разметка, правила уведомлений (без Android, покрыт тестами) |
| `YouTrackApi.kt` | REST API YouTrack |
| `Store.kt` | настройки, токен (Android Keystore, AES-GCM), прочитанное, план, кэш |
| `Sync.kt` | загрузка, фоновая проверка (WorkManager), уведомления |
| `MainViewModel.kt`, `Ui.kt`, `MainActivity.kt` | экраны (Jetpack Compose) |
| `TasksWidget.kt` | виджет на главный экран (Glance) |
