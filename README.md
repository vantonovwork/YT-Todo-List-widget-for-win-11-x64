# YouTrack Widget

Настольный виджет для Windows 11: задачи из YouTrack всегда под рукой, плюс план на день и свои срочные дела.

## Возможности

- **Задачи из YouTrack** — карточки с названием, статусом, приоритетом, сроком и спринтом. Клик по названию открывает задачу в браузере по умолчанию.
- **Поиск и фильтры** — по тексту, приоритетам, спринтам и «горящим» срокам (просрочено, сегодня, завтра).
- **Быстрый просмотр** — описание и последние комментарии прямо в карточке.
- **Комментарии в YouTrack** — «Написать комментарий» в быстром просмотре или в меню карточки: разметка YouTrack и `@упоминания`, Ctrl+Enter — отправить, неотправленный текст сохраняется как черновик.
- **Новые комментарии** — счётчик на карточке, в заголовке и на значке в трее, уведомления Windows о новых задачах и комментариях.
- **Смена статуса** из контекстного меню — только разрешённые переходы workflow.
- **План на день** — отмеченные звёздочкой задачи, порядок перетаскиванием, галочки «сделано» на сегодня.
- **Срочные задачи** — свои короткие дела (название до 100 символов, текст до 1000), хранятся только в виджете и в YouTrack не попадают.
- Темы и размер шрифта, значок в трее, горячая клавиша (по умолчанию `Win+Shift+Y`), автозапуск, установщик без прав администратора.

## Установка

Скачайте `YouTrackWidget-Setup.exe` (раздел Releases или соберите сами — см. ниже), запустите, выберите папку. При первом запуске укажите адрес YouTrack и постоянный токен (Профиль → Аккаунт и безопасность → Токены).

Запрос по умолчанию: `Assignee: me #Unresolved sort by: Priority`. Если поле приоритета у вас называется иначе (например, «Приоритет»), поправьте `sort by:` в настройках.

## Запуск из исходников

Нужен Python 3.12+ (только стандартная библиотека):

```powershell
py make_icon.py app.ico          # иконка (один раз)
pyw youtrack_widget.pyw
```

## Сборка exe и установщика

```powershell
py -m pip install --user pyinstaller
powershell -ExecutionPolicy Bypass -File build.ps1
```

Результат: `dist\YouTrackWidget-Setup.exe` (внутри — `YouTrackWidget.exe`).
Python берётся из переменной `YTW_PYTHON`, иначе через `py`, иначе из `PATH`.

## Тесты

```powershell
py -m pip install --user pyflakes
powershell -ExecutionPolicy Bypass -File tests\run_all.ps1          # всё, в песочнице
powershell -ExecutionPolicy Bypass -File tests\run_all.ps1 -Build   # + пересобрать exe перед тестами exe
powershell -ExecutionPolicy Bypass -File tests\run_all.ps1 -Real    # + проверка на вашем YouTrack (только чтение)
```

Тесты используют встроенный тестовый сервер YouTrack (`tests\mock_youtrack.py`) и отдельную папку настроек — ваши настройки, план и установленный виджет не затрагиваются.

## Где хранятся данные

`%APPDATA%\YouTrackWidget\`:

| Файл | Что внутри |
|---|---|
| `config.json` | настройки; токен зашифрован Windows DPAPI (расшифровать можно только под вашей учётной записью) |
| `seen.json` | какие комментарии уже прочитаны |
| `day_plan.json` | план на день и отметки «сделано» |
| `urgent.json` | срочные задачи |

## Структура

| Файл | Назначение |
|---|---|
| `youtrack_widget.pyw` | виджет |
| `installer.py` | установщик / деинсталлятор |
| `make_icon.py` | генерация иконки приложения |
| `build.ps1` | сборка exe и установщика (PyInstaller) |
| `fonts/` | шрифт иконок Material Icons Round (Apache 2.0, см. `fonts/NOTICE.md`) |
| `tests/` | автотесты и тестовый сервер YouTrack |
